Capital Bikeshare Demand Analysis & PredictionA data science project performing exploratory data analysis (EDA), statistical modeling, and machine learning on the Capital Bikeshare dataset (UCI Bike Sharing Dataset).
📌 Project OverviewThe objective of this project is to analyze hourly bike rental demand patterns in Washington, D.C., identify key environmental and temporal drivers, and build predictive models to forecast hourly rental counts.
📊 Key Findings & InsightsOverdispersion & Skewness: Hourly demand (count) is heavily right-skewed with high variance ($\mu \approx 189.5, \sigma \approx 181.4$).User Segments:Registered Users (~81.2%): Peak during commuter hours (8:00 AM and 5:00–6:00 PM) on working days.Casual Users (~18.8%): Peak during midday hours (12:00–4:00 PM) on weekends and holidays.Environmental Drivers: Temperature exhibits the strongest positive correlation with demand, while high humidity and severe weather significantly suppress rentals.
🛠️ Project Structure & TasksTask 1: Exploratory Data Analysis & Descriptive StatisticsDistribution and skewness analysis of total, registered, and casual counts.Visualizing hourly, daily, and seasonal trends across user types.Correlation matrix and collinearity inspection between continuous features (temp, atemp, humidity, windspeed).Task 2: Modeling Strategy & FormulationAddressing target skewness using $\log(1 + \text{count})$ transformation and Poisson / Negative Binomial GLMs.Handling collinearity between temperature variables.Selecting loss functions (RMSE on log-scale, RMSLE, MAE).Task 3: Validation Strategy & Feature EngineeringTemporal Validation Split: Implemented temporal time-series split to prevent data leakage from future timestamps.Feature Engineering: Extracted cyclical time encodings ($\sin/\cos$), lag features ($t-1, t-24$), and rolling statistics.
